# Website Approved Plans

This directory is the approved planning lane for the LawOps website and marketing repository.

Use this folder for:

- approved website redesign plans
- approved messaging overhauls
- approved campaign execution plans
- approved SEO or content programs
- approved multi-step initiatives that need sequencing

Rules:

- Only Adam-approved plans belong in this folder.
- Draft ideas, rough campaigns, and exploratory notes do not belong here.
- Unapproved work belongs in `.agents/drafts/`.
- Durable strategy memory belongs in `.agents/synopsis/`.
- Supporting reference material belongs in `.documentation/`.

Recommended structure:

- `.a-devplans/*.md` -> active approved plans
- `.a-devplans/archive/completed/*.md` -> completed approved plans
- `.a-devplans/archive/README.md` -> archive rules

Plan numbering rule:

- use a leading two-digit number for approved plans
- before creating a new number, check both:
  - active files in `.a-devplans/`
  - archived files in `.a-devplans/archive/completed/`

This keeps plan numbering unique across repo history.
