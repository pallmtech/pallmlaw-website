# LawOps Marketing Agent Workspace

This directory contains the operating layer for the LawOps marketing team.

Structure:

- `*.md` -> fixed agent charters
- `synopsis/*.md` -> durable marketing memory
- `drafts/*.md` -> campaign drafts, launch packets, and unapproved experiments
- `tasks/` -> background-agent task queue and task records

Rules:

- Website messaging must reflect shipped or credibly near-term LawOps capabilities.
- The stack must favor operational clarity over empty AI buzzwords.
- Estate Planning is the current primary ICP until Adam explicitly expands scope.
- Agent memory must avoid made-up customer proof, fake metrics, or invented testimonials.
- Final website, blog, social, and outbound copy should preserve the LawOps voice: operational, precise, ownership-driven, anti-chaos.
